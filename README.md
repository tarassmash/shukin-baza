# Sell Grid — Bybit Short (режим Щукина), сервер 24/7

Бот работает на сервере Railway круглосуточно, браузер держать открытым не нужно.

- `/` — панель сервера: позиции, возраст позиции, цели, лог, кнопка паузы
- `/manual` — старая ручная страница с графиками (не нажимай там «Старт» в live — будет два бота)
- `/health` — проверка (`ok`)

## Что делает бот
1. Каждые `SCAN_EVERY_MIN` минут сканирует USDT-перпы по 1m-волатильности (как кнопка «⚡ ультра-волатильные»), берёт топ `MAX_SYMBOLS` монет.
2. На цели ставит SELL-сетку выше цены (режим Щукина: шаг 1%, 5 уровней, 12 USDT/уровень, фильтр OI/CVD, защита от спайка, ATR-фильтр).
3. В шорте: тейк 0.7% (maker-лимит), аварийный стоп 10%, добор выше до `MAX_POS_USDT`.
4. **Позиция бота старше `MAX_HOLD_MIN` (90 мин) закрывается по рынку**, ордера бота по монете снимаются, монета уходит в кулдаун на `COOLDOWN_MIN`.
5. Если убыток бота за день (UTC) ≥ `MAX_DAILY_LOSS` — новые сетки не ставятся, открытые позиции бота продолжают контролироваться.

**Бот трогает только своё.** Позиция считается позицией бота, если она набрана ордерами бота (`orderLinkId` начинается с `sg_`) — это видно по истории сделок на бирже, поэтому переживает перезапуски. Ручные и чужие позиции бот не закрывает, не ставит на них TP/SL, не считает в дневном лимите и не ставит сетку на эти монеты. Снимает тоже только свои ордера.

## Размеры в % от баланса
Если заданы `ORDER_PCT` / `MAX_POS_PCT` / `MAX_DAILY_LOSS_PCT`, бот раз в минуту берёт баланс USDT (walletBalance)
и пересчитывает из него размер уровня, потолок на монету и дневной лимит. Пополнил счёт — сетка больше, после минусов — меньше.
Баланс считается по всему счёту: если на нём работает ещё один бот, его деньги тоже попадут в расчёт.

## Переменные Railway
| Переменная | По умолчанию | |
|---|---|---|
| `BYBIT_API_KEY`, `BYBIT_API_SECRET` | — | **обязательно** |
| `DASH_PASSWORD` | — | пароль панели (логин любой) |
| `LIVE` | `1` | `0` = только логи, без ордеров |
| `BYBIT_TESTNET` | `0` | `1` = testnet |
| `BOT_ENABLED` | `1` | `0` = старт на паузе |
| `MAX_HOLD_MIN` | `90` | макс. время жизни позиции |
| `MAX_SYMBOLS` | `1` | сколько монет из скана торговать |
| `MAX_OPEN_POSITIONS` | `3` | при стольких позициях новые монеты не берутся |
| `MAX_POS_USDT` | `120` | потолок добора в одну монету |
| `MAX_DAILY_LOSS` | `15` | USDT |
| `COOLDOWN_MIN` | `30` | пауза по монете после стопа/лимита времени |
| `SCAN_EVERY_MIN` | `5` | |
| `ORDER_PCT` | `0` | % баланса USDT на один уровень; если > 0 — главнее `ORDER_USDT` |
| `MAX_POS_PCT` | `0` | % баланса — потолок добора в одну монету; если > 0 — главнее `MAX_POS_USDT` |
| `MAX_DAILY_LOSS_PCT` | `0` | % баланса на начало суток UTC; если > 0 — главнее `MAX_DAILY_LOSS` |
| `GRID_STEP_PCT` `GRID_LEVELS` `TP_PCT` `SL_PCT` `ORDER_USDT` | `1` `5` `0.7` `4` `12` | в режиме Щукина шаг ≥1, TP ≥0.7, SL ≥2 |
| `CLOSE_MAKER_SEC` | `30` | закрытие позиции (тейк, стоп, лимит времени) — мейкер-лимитками, без маркета; столько секунд |
| `CLOSE_REPOST_SEC` | `1.5` | как часто переставлять лимитку закрытия |
| `CLOSE_SLIP_TICKS` | `10` | если за `CLOSE_MAKER_SEC` не закрылись — аварийная IOC-лимитка, не дальше N тиков за лучшей ценой |
| `TREND_FILTER` | `1` | шортить только падающие/слабые монеты; `0` = как раньше |
| `MAX_24H_PCT` | `0` | монета за 24ч не выше этого % (0 = только упавшие за сутки) |
| `MAX_30M_PCT` | `0` | движение за 30 мин не выше этого % |
| `MAX_5M_PCT` | `0.3` | движение за 5 мин не выше этого % |

**Фильтр тренда.** Скан берёт только монеты, которые за сутки в минусе, за последние 30 мин не выросли, за 5 мин не выросли больше чем на 0.3% и стоят ниже EMA20 (1m). Если уже выбранная монета пошла вверх, бот снимает свою сетку и не доливает шорт; уже открытую позицию ведёт дальше (тейк, стоп, лимит времени).

Регион сервера — **не США** (Bybit отдаёт 403 на IP из США). Сейчас: Singapore.
